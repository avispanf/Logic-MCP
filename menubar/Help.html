Logic MCP

Move Logic MCP.app into Applications, open it, then choose Install / repair service from its menu. The service runs at login and diagnostics remain available in manual mode.

Left-click the menu-bar button to switch modes. Right-click for setup and diagnostics. MANUAL · MCP OFF means known workers are stopped and unknown candidates were not detected. Enabling automation cancels paused jobs; start a new task afterwards. Interrupted audits can leave solo/transport settings in their last state: inspect the project before starting another audit.

Connect your MCP client

Use a client with Streamable HTTP support. Configure the core server:

[mcp_servers.logic-pro]
url = "http://127.0.0.1:8765/mcp"
tool_timeout_sec = 180

For plugin inspection and audio analysis, add two STDIO connections. Executable:

/Applications/Logic MCP.app/Contents/Resources/runtime/logic-mcp

Arguments are ["--plugins"] and ["--audio"], respectively. If installed in ~/Applications use that path instead. Restart the client after saving its configuration.

Logic and permissions

Open Logic. In Control Surfaces → Setup, assign Logic Control input and output to LogicProMCP-MCU-Internal [bridge]. The backend and the client running plugin tools need Accessibility and Automation access to Logic Pro / System Events. Grant these only in macOS System Settings when requested. The mode button itself needs no Accessibility permission.

Use Diagnostics to check the mode and backend. No open project is changed by the mode button. Start with a copy of a project when testing mixing tools. Numeric meters must actually be readable; unavailable measurements are reported as unavailable.

Recovery and removal

Repair manual state keeps automation blocked and backs up damaged state. Remove service cancels old workers and removes its login service. Remove MCP client entries afterwards, quit this app, then move it to the Trash. Keep project journals for manual recovery of interrupted audits.

Initial supported distribution: Apple Silicon, macOS 14+, with Logic integration measured on Logic Pro 12.3. Other combinations require validation. Unsigned development builds are for local testing; public stable downloads must be signed and notarized.
